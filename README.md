# URL Shortener

Сервис сокращения ссылок на Go.

## 🛠 Стек технологий

- **Язык:** Go 1.25
- **Роутер:** Chi Router (v5) + Render
- **База данных:** SQLite (драйвер `go-sqlite3`)
- **Валидация:** Go Playground Validator (v10)
- **Конфигурация:** Cleanenv, Godotenv
- **Тестирование:** Testify
- **Окружение:** Docker, Docker Compose, GitHub Actions (CI/CD)

---

## 🚀 Быстрый запуск

### 1. Настройка окружения
Создайте файл `.env` в корне проекта на основе примера:
```bash
cp .env.example .env
```

### 2. Запуск приложения
Проект настроен на запуск готового Docker-образа из Docker Hub:
```bash
make run
```
*Команда автоматически скачает свежий образ и запустит контейнер в фоне на порту `:8080`.*

---

## 🗄 Миграции (Локально)

Для управления схемами БД используется утилита `migrate` (должна быть установлена на вашем ПК).

- **Накатить миграции:** `make migrate-up`
- **Откатить последнюю:** `make migrate-down`
- **Создать новую миграцию:** `make migrate-create seq=имя_миграции`

---

## 🛠 Полезные команды (Makefile)

- `make env-up` — запуск контейнеров приложения.
- `make env-down` — остановка окружения.
- `make env-cleanup` — полная очистка локальной базы данных SQLite.
- `docker compose logs -f` — просмотр живых логов Go-сервера.
